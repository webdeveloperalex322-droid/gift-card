# Приёмка SEO

Единственный автоматический контур обратной связи проекта. Органический трафик —
главный канал, поэтому падение здесь блокирует задачу так же жёстко, как
упавшая сборка.

## Запуск

```bash
pnpm test:seo                                    # через шлюз, с автопропуском
BASE_URL=http://localhost:4321 pnpm test:seo     # против поднятого сайта
pnpm exec playwright test tests/seo/canonical.spec.ts   # один spec
pnpm exec playwright test --grep "canonical"            # по имени
```

## Три статуса шлюза

| Статус | Значение | Что делать |
|---|---|---|
| `PASSED` | тесты прогнаны против `BASE_URL`, все зелёные | продолжать завершение задачи |
| `FAILED` | нарушено конкретное требование | исправить; закрывать задачу нельзя |
| `SKIPPED` | нет spec-файлов или не задан `BASE_URL` | **не проверено**; перенести статус в отчёт дословно |

`SKIPPED` существует, чтобы скелет проекта имел зелёный `verify` до появления
сайта. Он не является прохождением. Выдача `SKIPPED` за `PASSED` — самая дорогая
ошибка отчётности в этом проекте: она снимает единственную страховку с
приоритетного требования.

## Тестовая выборка (п. 22 ТЗ)

Главная, раздел, праздничная посадочная, дочерняя подборка, карточка, пагинация,
внутренний поиск, URL с параметрами, удалённая карточка, 404.

## Правило одного требования на spec

Каждое требование чек-листа — отдельный spec-файл с говорящим именем
(`canonical.spec.ts`, `sitemap-only-indexable.spec.ts`, `no-orphans.spec.ts`).
Падение должно называть нарушенное требование, а не сообщать «SEO сломано».

## Установка Playwright

Ставит агент `seo-auditor` вместе с первым spec-файлом:

```bash
pnpm add -D -w @playwright/test
pnpm exec playwright install chromium
```

Конфиг — `tests/seo/playwright.config.ts`, `baseURL` берётся из `BASE_URL`.

## Проверка «страница полноценна без JS»

Ключевой инвариант рендеринга проверяется контекстом с отключённым JS:

```ts
const context = await browser.newContext({ javaScriptEnabled: false });
```

Если при отключённом JS исчезает title, H1, canonical, текст, ссылки или первые
изображения — это нарушение запрета «скрывать контент за JavaScript».
