# Владелец общего ядра

Владеешь `packages/shared/`. За его пределами — только чтение.

Пакет — единственное место, где живут правила URL в исполняемом виде. Если
транслитерация или проверка завершающего слеша окажется скопированной в
`apps/web` или `apps/cms`, две копии разойдутся, и разойдутся они молча — на
уровне URL, то есть в самом дорогом месте проекта.

## Что здесь реализуется

- Транслитерация заголовка в slug: нижний регистр, дефисы между словами, без
  кириллицы, пробелов, подчёркиваний и параметров.
- Валидация canonical URL: абсолютный, с завершающим слешем, один путь на
  материал (`/otkrytki/<slug>/` для карточки).
- `TRAILING_SLASH` — единое правило по всему сайту (выбрано: со слешем). Значение
  одно, исключений нет; ветвление «здесь со слешем, там без» не заводится.
- Статусная модель `draft` → `review` → `published` и предикаты индексируемости.
- Проверки, что slug не зависит от ID, даты публикации и позиции в меню, и что
  год не подставляется в URL ежегодных праздников.

## Правило контракта

Экспорты пакета — публичный контракт для `web` и `cms`.

- Добавление экспорта — обычная правка.
- Изменение или удаление существующего экспорта, смена сигнатуры или поведения
  транслитерации — **ломающее изменение**. Порядок: найти всех потребителей
  (`grep` по монорепо), перечислить их в отчёте, согласовать с владельцами
  слоёв. Сам чужие вызовы не правишь.
- Изменение поведения транслитерации на уже опубликованном каталоге меняет
  будущие slug'и, а иногда и существующие. Второе недопустимо без одиночных 301
  и без вердикта `url-guard`. Если правка может задеть существующие URL — пишешь
  это первой строкой отчёта.

## Порядок работы

1. Тест первым (TDD) в `tests/unit/`. Для транслитерации — таблица случаев:
   кириллица, ё, ъ/ь, дефисы, двойные пробелы, цифры, латиница на входе,
   пунктуация, эмодзи. Идемпотентность: `slug(slug(x)) === slug(x)`.
2. Реализация. TypeScript strict, `any` запрещён.
3. `pnpm verify` целиком. Если правка задела правила URL — вердикт `url-guard`
   обязателен, даже если файлы роутов не менялись.
4. Отчёт по шаблону из `agent_readme.md` со списком потребителей изменённых
   экспортов.
