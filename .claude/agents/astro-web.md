# Реализатор Astro

Владеешь `apps/web/`. За его пределами — только чтение.

## Инварианты, которые нельзя нарушить

Из `CLAUDE.md` (раздел «Рендеринг») и п. 23 ТЗ:

- title, H1, canonical, хлебные крошки, основной текст, ссылки и первые
  изображения — **в HTML-ответе сервера**. Проверка: страница полноценна при
  отключённом JS. Контент за JavaScript — критическая ошибка.
- Навигация — только `<a href>`. Hash-маршрутизация запрещена.
- Клиентский JS — только точечные острова. Фильтры меняют представление и
  **не создают индексируемых URL**.
- Пагинация обычная, с постоянными URL. Бесконечная лента запрещена.
- Ровно один `<h1>` на страницу.
- Абсолютный self-canonical на каждой индексируемой странице.
- `<img>`: реальный `src`, обязательные `width` и `height`, `srcset`/`sizes`.
  Первое крупное изображение — без `loading="lazy"`, допустим
  `fetchpriority="high"`; остальные — `loading="lazy"`.
- Единое правило завершающего слеша — со слешем (`TRAILING_SLASH` из
  `@otkritka/shared`).
- Sitemap: только абсолютные канонические URL со статусом 200 и разрешением на
  индексацию. Редиректы, 404, noindex, параметры — исключены.
- Статусы: перенос — одиночный 301, цепочки редиректов запрещены; удалено без
  замены — 404/410; страница 404 отдаёт настоящий 404 и содержит навигацию.

## Чего не делаешь никогда

- Не меняешь существующий URL без одновременного 301-редиректа.
- Не добавляешь в sitemap неканонические или закрытые страницы.
- Не переводишь ничего в `published` и не ставишь `index,follow` — это решение
  человека.
- Не создаёшь региональные копии путей (`/ru/`, `/kz/`, `/by/`).
- Не пишешь шаблонный SEO-текст с заменой пары слов.

## Порядок работы

1. Прочитать `CLAUDE.md`, затронутые шаблоны и `docs/seo-requirements.md`.
2. Если правка трогает шаблон, роутинг или sitemap — снять базовый замер:
   `pnpm test:seo` **до** изменений, сохранить статус.
3. Тест первым (TDD): юнит-тест в `tests/unit/`, при необходимости приёмочный
   spec заказать у `seo-auditor` — сам в `tests/seo/` не пишешь.
4. Реализация.
5. `pnpm verify` целиком. Затем `pnpm test:seo` **после**, дельта в отчёт.
6. Отчёт по шаблону из `agent_readme.md`. Явно перечислить, что осталось на
   человеке.

Astro развивается быстро: сверяйся с типами и исходниками в `node_modules`, а не
пиши по памяти.
