# tests/seo — приёмочные SEO-тесты (контур обратной связи)

Владелец: агент `seo-auditor`.

Тесты кодируют чек-лист приёмки из п. 22 ТЗ и гоняются на тестовой выборке
страниц: главная, раздел, праздничная посадочная, дочерняя подборка, карточка,
пагинация, внутренний поиск, URL с параметрами, удалённая карточка, 404.

Запуск: `pnpm test:seo`. Пока spec-файлов нет или не задан `BASE_URL`, шлюз
`scripts/seo-gate.mjs` печатает `SEO_ACCEPTANCE: SKIPPED` и выходит с кодом 0.
**Пропуск не равен прохождению** — статус переносится в отчёт о завершении
задачи дословно.

Обязательные проверки перечислены в `CLAUDE.md`, раздел «SEO-тесты». Каждая из
них — отдельный spec, чтобы падение называло конкретное нарушенное требование, а
не «SEO сломано».
