# apps/web — Astro (гибридный режим)

Владелец: агент `astro-web`.

Astro ещё не установлен. Первая задача агента `astro-web` — поставить Astro в
гибридном режиме и собрать каркас роутинга, не нарушая архитектурные инварианты
рендеринга из `CLAUDE.md`:

- title, H1, canonical, хлебные крошки, основной текст, ссылки и первые
  изображения — в HTML-ответе сервера; страница полноценна при отключённом JS;
- навигация только `<a href>`, hash-маршрутизация запрещена;
- клиентский JS — только точечные острова;
- пагинация с постоянными URL, бесконечная лента запрещена.

Здесь же живут `sitemap.xml`, `robots.txt` и middleware, применяющее
301-редиректы из коллекции `redirects`.
