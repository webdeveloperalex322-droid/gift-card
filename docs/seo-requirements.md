# SEO ТЗ — источник истины

> **Каркас, не содержание.** Настоящего текста ТЗ в репозитории пока нет.
> `CLAUDE.md` называет этот файл источником истины при любых противоречиях,
> поэтому файл создан как указатель — но его содержание агентами не
> восстанавливается и не выдумывается. Заполняет человек, из оригинала ТЗ.

## Как этим пользоваться до заполнения

`CLAUDE.md` содержит выжимку требований и ссылается на пункты ТЗ по номерам.
Пока полного текста нет, действует правило:

- требование есть в `CLAUDE.md` — выполняем по `CLAUDE.md`;
- требование только упомянуто номером пункта, а формулировки нет — это **вопрос
  человеку**, а не повод для догадки. Агент пишет его в раздел «Требует решения
  человека» отчёта о завершении задачи.

появления полного текста.
