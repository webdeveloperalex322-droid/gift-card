### Решения, принятые при реализации (нормы проекта)

- **Таблица транслитерации** — практика BGN/PCGN, посимвольно. Два решения содержательные, не косметические: `х → kh` (при `h` сочетание «сх» сливается с «ш», и «Пасха» с «Паша» дали бы один slug — коллизия URL двух разных материалов) и `ё → e` (иначе «Ёлка» и «Елка» дают два URL и лишний 301). `ц → ts`, потому что `c` неотличим от «к».
- **Правило отказа `slugify`** — критерий не письменность, а результат: любая литера, не давшая после таблицы и снятия диакритики ни одного допустимого символа, обрывает транслитерацию целиком. Отказ всей строки, а не пропуск литеры: иначе «Открытки для Наталії» дало бы `otkrytki-dlya-natali`, правдоподобный slug другого слова. Одиночные комбинирующие метки при этом отбрасываются (`İstanbul → istanbul`, «по́здравления» → `pozdravleniya`), латиница с диакритикой теряет диакритику (`Café → cafe`).
- **Расширение JPEG — только `.jpg`** (Ч-30, ждёт подтверждения). Два написания одного содержимого — это два URL одной картинки.
- **Абсолютный URL изображения не собирается нигде**: пакет возвращает только относительные ключи объектов, хост не появляется даже параметром с дефолтом. Причина — незакрытое противоречие между правилом «единственный хелпер над `SITE_URL`» и отдельным `IMAGES_CDN_ORIGIN` из Ч-03.
- **`revision` в ключе производной** — параметр без дефолта (Ч-28). В ТЗ его нет дословно; он необходим, потому что §6.7 («замена изображения даёт новые URL производных») несовместим с immutable-кешированием без версионирования.

### Что контролёры перепроверили экспериментом, а не приняли на слово

- Защита pHash от контейнера: с `fastShrinkOnLoad: false` расстояние PNG↔WebP = 0, без флага = 8. Восемь бит шума равны расстоянию реально похожей картинки — без флага порог либо пропускал бы дубли, либо тонул в ложных срабатываниях.
- Негативная фикстура pHash изначально была поворотом той же сетки на 180°, а не другой картинкой, и из неё в `.env.example` ушло «другая композиция — 28». Заменена на радиальную структуру, все замеры перепроверены независимо и совпали до единицы.
